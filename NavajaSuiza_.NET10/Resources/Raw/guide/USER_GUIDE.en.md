## 1. Sketchpad

The sketchpad lets you draw freehand on a white surface and save your drawing as an image.

| | |
|---|---|
| ![Sketchpad](blackboard_01.jpg) | ![Sketchpad](blackboard_02.jpg) |

### How to use it

- Pick a color with the palette button (color wheel).
- Draw by dragging your finger across the white surface.
- Use the eraser to correct a stroke.
- Undo the last stroke with the arrow button.
- Clear the whole sketchpad with the trash button.
- Save your drawing as an image with the save button.

### Tips

- Stroke thickness is adjusted with the slider at the top.
- The sketchpad adapts to the app's light and dark theme.
- If you change the background color, the pen adjusts its contrast automatically so it is always visible.

## 2. Tuner

The tuner lets you play the notes of several instruments so you can tune yours by ear. These are available:

- Acoustic and classical guitar (nylon).
- Steel guitar.
- Bass.
- Ukulele.
- Violin.
- Charango.

| | |
|---|---|
| ![Tuner](tuner_01.jpg) | ![Tuner](tuner_02.jpg) |

### How to use it

1. Pick the instrument from the list.
2. Touch the string you want to hear: it plays the reference note.
3. Adjust your instrument until the sound matches the string.

### Reference notes per instrument

| Instrument | Notes (low to high) |
|---|---|
| Nylon guitar | E2 · A2 · D3 · G3 · B3 · E4 |
| Steel guitar | E2 · A2 · D3 · G3 · B3 · E4 |
| Bass | E1 · A1 · D2 · G2 |
| Ukulele | G4 · C4 · E4 · A4 |
| Violin | G3 · D4 · A4 · E5 |
| Charango | G4 · C5 · E5 · E4 · A4 · E5 |

### Tips

- Use a quiet place to hear the note clearly.
- On the charango some strings are double (x2): they play the same note twice.

## 3. Metronome

The metronome helps you keep a steady rhythm while you practice or play.

| | |
|---|---|
| ![Metronome](metronome_01.jpg) | ![Metronome](metronome_02.jpg) |

### How to use it

1. Adjust the speed with the BPM control (beats per minute).
2. Pick the time signature: 3/4, 4/4, 5/4, 6/8 or 7/8.
3. Tap **Play** to start and **Stop** to stop it.

### Tips

- Start slow (60–80 BPM) and increase the speed gradually.
- On accented time signatures (for example 4/4), the first beat sounds stronger.

## 4. Stopwatch

The stopwatch measures time with laps, ideal for workouts or precise measurements.

| | |
|---|---|
| ![Stopwatch](stopwatch_01.jpg) | ![Stopwatch](stopwatch_02.jpg) |

### How to use it

- Tap the **play** button to start measuring.
- While running, the same play button records a **lap** (shows accumulated and split time).
- Tap the **stop** button to pause.
- Tap the **stop** button a second time (when stopped) to reset: it goes back to zero and clears the laps.

### Tips

- Laps are shown in the list at the bottom, from the most recent to the oldest.
- The stopwatch keeps its state while you re-enter the tool in the same session.

## 5. Flashlight

The flashlight turns your phone camera into a light source and also includes a screen light and emergency signals in Morse code.

| | |
|---|---|
| ![Flashlight](flashlight_01.jpg) | ![Flashlight](flashlight_02.jpg) |

### How to use it

- Tap the **flash** button to turn the camera light on or off.
- Tap **screen light** to use the white screen as a light (great for reading).
- Use **SOS** to send the SOS distress signal in Morse.
- Use **HELP** to send the HELP signal in Morse.

### Tips

- Turn off the screen light when you leave: the app restores your device's original brightness.
- Morse signals play using the flash light; tap the same button to stop them.

## 6. Compass

The compass shows you magnetic north and the exact angle in degrees, with smoothed readings for greater stability.

| | |
|---|---|
| ![Compass](compass_01.jpg) | ![Compass](compass_02.jpg) |

### How to use it

- Hold the phone flat: the needle points north and the angle is shown in degrees.
- The direction is shown as text (N, NE, E, SE, S, SW, W, NW).
- The tilt indicator warns you when the phone is not flat.

### Calibration

- Tap **Calibrate** and move the device in a figure-eight in the air while the app measures.
- Calibration takes a few seconds and improves the accuracy of the reading.

## 7. Notes

The notes tool lets you write down ideas, tasks or any text, and keep them organized and searchable.

| | |
|---|---|
| ![Notes](notes_01.jpg) | ![Notes](notes_02.jpg) |

### How to use it

- Tap the **new note** button to create a note.
- Write a title and the content.
- Tap **save** to save it or **back** to cancel without saving.
- Tap an existing note to edit it.
- Use the magnifier to search by title or content.
- Tap the delete (trash) button to remove a note; the app asks for confirmation.

### Tips

- Notes are sorted from the most recent to the oldest.
- If a note has no title or content, it is not saved.

## 8. Document reader

The document reader opens and displays all kinds of files without leaving the app.

| | |
|---|---|
| ![Document reader](viewer_01.jpg) | ![Document reader](viewer_02.jpg) |

### Supported formats

| Type | Description |
|---|---|
| PDF | Shown directly. |
| DOCX / XLSX / DOC / XLS | Converted to PDF in the background and then shown. |
| CSV | The delimiter is detected (comma, semicolon or tab) and converted. |
| Text (.txt) | Shown as plain text with its file name. |

### How to use it

1. Tap **Document reader** in the menu.
2. Pick the file in the system picker.
3. The document opens automatically in the viewer.

### Tips

- Office files go through a conversion; a progress indicator appears while it is prepared.
- Very large text files are not opened (size limit to protect performance).

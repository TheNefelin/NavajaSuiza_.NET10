## 1. Ritplatta

Ritplattan låter dig rita fritt för hand på en vit yta och spara din teckning som bild.

| | |
|---|---|
| ![Ritplatta](blackboard_01.jpg) | ![Ritplatta](blackboard_02.jpg) |

### Så här använder du den

- Välj en färg med palettknappen (färghjulet).
- Rita genom att dra fingret över den vita ytan.
- Använd suddgummit för att rätta till ett streck.
- Ångra det senaste strecket med pilknappen.
- Rensa hela ritplattan med papperskorgsknappen.
- Spara din teckning som bild med spara-knappen.

### Tips

- Streckets tjocklek ställs in med reglaget överst.
- Ritplattan anpassar sig till appens ljusa och mörka tema.
- Om du ändrar bakgrundsfärgen justerar pennan sin kontrast automatiskt så att den alltid syns.

## 2. Stämapparat

Stämapparaten låter dig spela upp tonerna från flera instrument så att du kan stämma ditt eget instrument på gehör. Dessa finns tillgängliga:

- Akustisk och klassisk gitarr (nylon).
- Steel-gitarr.
- Bas.
- Ukulele.
- Violin.
- Charango.

| | |
|---|---|
| ![Stämapparat](tuner_01.jpg) | ![Stämapparat](tuner_02.jpg) |

### Så här använder du den

1. Välj instrument från listan.
2. Tryck på strängen du vill höra: referenstonen spelas upp.
3. Stäm ditt instrument tills ljudet stämmer med strängen.

### Referenstoner per instrument

| Instrument | Toner (från låg till hög) |
|---|---|
| Nylongitarr | E2 · A2 · D3 · G3 · B3 · E4 |
| Steel-gitarr | E2 · A2 · D3 · G3 · B3 · E4 |
| Bas | E1 · A1 · D2 · G2 |
| Ukulele | G4 · C4 · E4 · A4 |
| Violin | G3 · D4 · A4 · E5 |
| Charango | G4 · C5 · E5 · E4 · A4 · E5 |

### Tips

- Använd en tyst plats för att höra tonen tydligt.
- På charango är vissa strängar dubbla (x2): de spelar samma ton två gånger.

## 3. Metronom

Metronomen hjälper dig hålla en jämn rytm när du övar eller spelar.

| | |
|---|---|
| ![Metronom](metronome_01.jpg) | ![Metronom](metronome_02.jpg) |

### Så här använder du den

1. Justera hastigheten med BPM-reglaget (slag per minut).
2. Välj taktart: 3/4, 4/4, 5/4, 6/8 eller 7/8.
3. Tryck på **Play** för att starta och **Stop** för att stänga av.

### Tips

- Börja långsamt (60–80 BPM) och öka hastigheten successivt.
- I betonade taktarter (till exempel 4/4) låter första slaget starkare.

## 4. Stoppur

Stoppuret mäter tid med varv, perfekt för träning eller precisa mätningar.

| | |
|---|---|
| ![Stoppur](stopwatch_01.jpg) | ![Stoppur](stopwatch_02.jpg) |

### Så här använder du det

- Tryck på **play**-knappen för att börja mäta.
- Medan tiden rinner registrerar samma play-knapp ett **varv** (visar ackumulerad tid och varvtid).
- Tryck på **stop**-knappen för att pausa.
- Tryck på **stop**-knappen en andra gång (när det är stoppat) för att nollställa: det går tillbaka till noll och rensar varven.

### Tips

- Varv visas i listan längst ner, från det nyaste till det äldsta.
- Stoppuret behåller sitt tillstånd när du går in i verktyget igen under samma session.

## 5. Ficklampa

Ficklampan gör din telefonkamera till en ljuskälla och inkluderar även en skärmlampa och nödsignaler i morsealfabetet.

| | |
|---|---|
| ![Ficklampa](flashlight_01.jpg) | ![Ficklampa](flashlight_02.jpg) |

### Så här använder du den

- Tryck på **blixt**-knappen för att tända eller släcka kameraljuset.
- Tryck på **skärmljus** för att använda den vita skärmen som ljuskälla (perfekt för läsning).
- Använd **SOS** för att sända nödsignalen SOS i morse.
- Använd **HELP** för att sända hjälpsignalen HELP i morse.

### Tips

- Stäng av skärmljuset när du lämnar appen: appen återställer enhetens ursprungliga ljusstyrka.
- Morsesignalerna spelas med blixtljuset; tryck på samma knapp för att stoppa dem.

## 6. Kompass

Kompassen visar magnetisk norr och den exakta vinkeln i grader, med utjämnade avläsningar för bättre stabilitet.

| | |
|---|---|
| ![Kompass](compass_01.jpg) | ![Kompass](compass_02.jpg) |

### Så här använder du den

- Håll telefonen platt: nålen pekar mot norr och vinkeln visas i grader.
- Riktningen visas som text (N, NO, O, SO, S, SV, V, NV).
- Lutningsindikatorn varnar dig när telefonen inte ligger platt.

### Kalibrering

- Tryck på **Kalibrera** och rör enheten i en åtta i luften medan appen mäter.
- Kalibreringen tar några sekunder och förbättrar avläsningens noggrannhet.

## 7. Anteckningar

Med anteckningsverktyget kan du skriva ner idéer, uppgifter eller valfri text och hålla dem ordnade och sökbara.

| | |
|---|---|
| ![Anteckningar](notes_01.jpg) | ![Anteckningar](notes_02.jpg) |

### Så här använder du det

- Tryck på knappen **ny anteckning** för att skapa en anteckning.
- Skriv en titel och innehållet.
- Tryck på **spara** för att spara eller **tillbaka** för att avbryta utan att spara.
- Tryck på en befintlig anteckning för att redigera den.
- Använd förstoringsglaset för att söka på titel eller innehåll.
- Tryck på radera-knappen (papperskorgen) för att ta bort en anteckning; appen ber om bekräftelse.

### Tips

- Anteckningar sorteras från den nyaste till den äldsta.
- Om en anteckning saknar både titel och innehåll sparas den inte.

## 8. Dokumentläsare

Dokumentläsaren öppnar och visar olika typer av filer utan att du behöver lämna appen.

| | |
|---|---|
| ![Dokumentläsare](viewer_01.jpg) | ![Dokumentläsare](viewer_02.jpg) |

### Stödda format

| Typ | Beskrivning |
|---|---|
| PDF | Visas direkt. |
| DOCX / XLSX / DOC / XLS | Konverteras till PDF i bakgrunden och visas sedan. |
| CSV | Avgränsaren detekteras (kommatecken, semikolon eller tabb) och konverteras. |
| Text (.txt) | Visas som vanlig text med sitt filnamn. |

### Så här använder du den

1. Tryck på **Dokumentläsare** i menyn.
2. Välj filen i systemets filväljare.
3. Dokumentet öppnas automatiskt i visaren.

### Tips

- Office-filer går igenom en konvertering; en förloppsindikator visas medan den förbereds.
- Mycket stora textfiler öppnas inte (storleksgräns för att skydda prestandan).
